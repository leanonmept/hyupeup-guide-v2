# 장기요양기관 휴·폐업 준비 도우미 v2

휴·폐업 자료이관 준비를 4단계 진단으로 정리해 주는 정적 웹앱(PWA)입니다.
기존 앱(저장소 `hyupeup-guide-ref`, v29)의 업무 내용·공식 서식·규정 문구를 그대로 유지하고, 화면 구조와 디자인을 처음부터 다시 만들었습니다.

## 파일 구성

```
index.html                화면 4개 탭 (맞춤진단 / 서식·예시 / 편철·계산 / 질문·점검)
styles.css                디자인 시스템 (네이비 #16325C · 블루 #2563EB · #F4F6F9 배경)
app.js                    진단 로직, 61개월 계산, 편철 구조 생성, 체크리스트 저장
manifest.webmanifest      PWA 설정
sw.js                     오프라인 캐시 (앱 + 서식 PDF + 미리보기 이미지)
assets/forms/*.pdf        공단 별지 서식 원본 5종
assets/forms/binding/*.pdf 편철 별지 7종 (별지 제22호 ~ 제26호)
assets/previews/*.png     서식 1쪽 미리보기 이미지 (모달 표시용)
assets/transfer_list_example.png  이관목록표 작성예시
icons/                    앱 아이콘
previews/                 검증용 스크린샷
```

## 로컬에서 보기

```bash
cd hyupeup-guide-v2
python3 -m http.server 8765
# 브라우저에서 http://127.0.0.1:8765/ 접속 (모바일 390x844 기준)
```

`file://`로 열면 서비스워커와 일부 상대경로가 동작하지 않으니 로컬 서버로 확인하세요.

## GitHub Pages 배포

1. 이 폴더의 **내용물 전체**를 저장소 최상위(root)에 올립니다.
2. 저장소 → Settings → Pages → Build and deployment에서 `Deploy from a branch` 선택.
3. Branch `main`, 폴더 `/(root)`로 저장.
4. `https://<사용자명>.github.io/<저장소명>/` 로 접속합니다.

`index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `assets/`, `icons/`의 상대 경로를 유지해야 합니다.
업데이트 후 캐시가 남으면 `sw.js`의 `CACHE` 이름(`hyupeup-guide-v2-1`)을 올려 주세요.

## 동작 메모

- **진단 상태·체크리스트·글자 크기**는 `localStorage`의 `hyupeup-v2` 키 하나에 저장됩니다.
- **61개월 계산**: 휴·폐업 예정월을 포함해 61개월. 시작월·종료월 모두 그 달 전체를 포함합니다(예: 2026.11 → 2021.11 ~ 2026.11).
- **편철 구조**: 접속연도 포함 최근 6개년, 급여종류 10종 복수 선택. 공통서류는 2026년 개정 서식(별지 제24호·제24호의2·제24호의3, 2026. 1. 1. 시행) 기준이며, 2026년 이전 연도는 당시 서식명으로 표시합니다.
- **서식 미리보기**: PDF 1쪽을 이미지로 렌더링해 모달에 표시하고, `PDF 원본 열기`로 원본을 엽니다. 외부 CDN·외부 요청은 사용하지 않습니다.
- 2027년 이후 연도는 별도 개정 정보가 연결되기 전까지 2026년 편철 구조를 기본값으로 표시합니다.

## 원본 앱에서 유지한 업무 규칙

- 신청서·이관 목록표는 모든 경우 기본 작성, 분실 시 분실 및 훼손 목록표·확인서, 대리인 방문 시 위임장·신분증·인감증명서(최근 3개월 이내).
- 이관대상: 급여계약 서류, 급여제공기록지 등, 방문간호지시서, 급여비용 명세서 부본. **급여비용 청구서·청구명세서는 이관 제외**.
- 휴업기관은 휴업 예정일 전에 자체보관을 신청해 공단 허가를 받은 경우 기관 보관이 가능합니다.
- 편철: 연도 변경 시 새 권, 약 300매 1권, 수급자 자료는 중간에 끊지 않기, 각 자료 우측하단에 연필로 매수 기입.
- 진행 순서: ① 공단 접수 → ② 접수증 수령 → ③ 시·군·구 신고.
